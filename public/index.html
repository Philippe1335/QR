🔌 API pour le POS

Authentification par clé API (header X-API-Key). Démo : rest_demo / demo_key_123.

  • POST /api/v1/factures — créer une facture → checkout_url + QR code
  • GET /api/v1/factures/:id — statut (paid / pending), montants, tip
  • DELETE /api/v1/factures/:id — annuler
  • GET /api/v1/analytics?rest_id=…&period=week — tous les insights en JSON
  • Webhook payment.completed envoyé au POS après chaque paiement
